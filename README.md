\# 🚚 Logistics \& Supply Chain Analytics



\## 📌 Project Overview



This project analyzes logistics and supply chain operations using Python, Pandas, and Streamlit.



The project focuses on delivery performance, fleet operations, driver safety, warehouse utilization, fuel costs, and vehicle maintenance.



\## 🎯 Project Objectives



\- Analyze delivery delays and traffic conditions

\- Understand fleet and fuel-type distribution

\- Analyze driver safety performance

\- Monitor warehouse utilization

\- Analyze fuel and maintenance costs

\- Identify operational insights

\- Build an interactive Streamlit dashboard



\## 🛠️ Tools \& Technologies



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Streamlit

\- Jupyter Notebook



\## 📊 Dashboard Features



\- Executive KPI overview

\- Delivery performance analysis

\- Fleet performance analysis

\- Driver performance analysis

\- Warehouse performance analysis

\- Cost analysis

\- Maintenance analysis

\- Interactive filters for Year, Traffic, and Fuel Type

\- Business insights
